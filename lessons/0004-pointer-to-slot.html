A Pointer to the Slot

An array owns pointers, each pointer owns a string, and a char** lets a function replace one pointer in the caller's array.

About 30 minutes Where: WSL, exercises/04-word-slots/ Mission · Cheat sheet · Lesson 3
Your win today. Build and free a two-level heap shape, find a string with strcmp, return the address of its slot, replace its owned string through char**, and keep every ownership obligation balanced on failure.

A C string is an address plus a stopping rule

The literal "pear" stores five bytes:

address:   +0    +1    +2    +3    +4
byte:      'p'   'e'   'a'   'r'   '\0'
                                      ^ zero byte marks the end

A char* points at the first byte. C does not store the length beside that pointer. String functions walk bytes until the zero byte called the null terminator. Beej describes the rule as “a zero-valued byte … after the pointer that indicates the end of the string”*.

ExpressionResult
strlen("pear")4. The terminator is not counted. Result type is size_t.
strcmp(a, b) == 0The two strings contain equal bytes.
strcmp(a, b) < 0a comes before b lexicographically.
strdup(s)A new heap copy, or NULL. The caller owns and frees it.

strcmp is not a boolean equality function. Zero means equal. Writing if (strcmp(a, b)) enters the branch when the strings differ.

A pointer assignment does not copy a string.

const char* source = "pear";
const char* alias = source;       /* two pointers, one string */
char* copy = strdup(source);      /* second string on the heap */

Do not modify or free a string literal. A successful strdup result is a normal owned heap block and must be freed*. This project uses -std=gnu11, so <string.h> declares strdup.

An array of pointers creates two ownership levels

After duplicating three strings, memory has this shape:

main stack             heap: pointer array          heap: strings
+-----------+          +------------------+         +----------------+
| words ----+--------->| [0] -------------+-------->| "pear\0"       |
+-----------+          | [1] -------------+---+     +----------------+
                       | [2] ----------+   |   +---->| "fig\0"        |
                       +---------------|---+         +----------------+
                                       +------------>| "banana\0"     |
                                                    +----------------+

words has type char**: it points to the first char* slot. The outer heap block owns three pointer slots. Each slot owns a separate string block. Cleanup reverses construction:

for (size_t i = 0; i < n; i++) {
    free(words[i]);       /* free each inner string */
}
free(words);              /* then free the outer pointer array */

Freeing only words leaks every string. Freeing only the strings leaks the pointer array. This two-level shape is the minimum needed later for hashmap buckets and graph adjacency lists.

char** means “address of a pointer slot”

Suppose words[1] contains the pointer to "fig". These expressions move through the two levels:

ExpressionTypeMeaning
wordschar**Address of the first slot.
words + 1char**Address of slot 1.
&words[1]char**The same address of slot 1.
words[1]char*Pointer stored in slot 1: address of "fig".
*words[1]charThe first character, 'f'.
char** slot                    char* in caller's slot       characters
+-----------+                  +------------------+         +---------+
|     ------+----------------->| words[1] --------+-------->| fig\0    |
+-----------+                  +------------------+         +---------+
       slot points to the caller's pointer, not directly to the chars

A function that receives only char* current receives a copy of the string address. Assigning current = copy changes only that local copy. A function that receives char** slot can assign *slot = copy, which changes the pointer stored in the caller's array. Beej reaches the same rule through &p: the address of a pointer has pointer-to-pointer type*.

Replacement must preserve the old owner if duplication fails:

char* copy = strdup(replacement);
if (copy == NULL) {
    return 0;              /* *slot still owns the old string */
}
free(*slot);               /* end old string's lifetime */
*slot = copy;              /* caller's slot now owns the copy */
return 1;

The order matters. Freeing *slot before strdup would destroy the old value even when allocation fails.

The interface

words.h

#pragma once

#include <stddef.h>

/* Find target among the n strings at words.
   Returns the address of the matching pointer slot, or NULL if absent. */
char** words_find(char** words, size_t n, const char* target);

/* Replace the owned string at *slot with a heap copy of replacement.
   Returns 1 on success. On failure, returns 0 and leaves *slot unchanged. */
int word_replace(char** slot, const char* replacement);

/* Return the longest of n strings. n must be at least 1.
   Returns a borrowed pointer owned by the array. */
const char* words_longest(char** words, size_t n);

/* Free n owned strings, then free their pointer array. Consumes ownership. */
void words_free(char** words, size_t n);

words_longest only reads the array, so its parameter is plain char**. The const char* on its return is the part that matters: it says the pointer is borrowed, owned by the array, and must not be freed by the caller. C has a stricter form, char* const*, that also stops the function from reassigning a slot. It is deferred to a later lesson; the const char* forms you already use are enough here.

Reading the pointer-level failure

The planted free(slot) bug passes the address of a pointer slot, not the pointer stored there. For slot 1, AddressSanitizer reports a bad free at an address eight bytes inside the 24-byte outer block:

ERROR: AddressSanitizer: attempting free on address which was not malloc()-ed
    #0 ... in free
    #1 ... in word_replace words.c:...
...
address is located 8 bytes inside of 24-byte region
allocated by ... calloc ... main.c:...

Three slots × eight-byte pointers explain 24 bytes. Slot 1 begins eight bytes into that array. The report therefore tells you that one dereference is missing: slot addresses the slot; *slot is the separately allocated string pointer that may be freed.
