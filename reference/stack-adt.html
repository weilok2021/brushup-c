Stack ADT

A dynamic-array stack as a module: opaque struct, two owned heap blocks, doubling growth through a temporary pointer, and status-plus-out-parameter contracts. Paired with Lesson 9. Lessons 10, 11 and 12 reuse this shape.

The ADT shape (copy for every structure)

stack.h · what the client sees

#pragma once
#include <stddef.h>

typedef struct stack stack_t;   /* name only */

stack_t* stack_new(void);
void     stack_free(stack_t* s);
int      stack_push(stack_t* s, int value);
int      stack_pop(stack_t* s, int* out);
int      stack_peek(const stack_t* s, int* out);
size_t   stack_count(const stack_t* s);

stack.c · the shape, private

#include "stack.h"
#include <stdlib.h>

#define INITIAL_CAPACITY 2

struct stack {
    int* items;      /* owned block */
    size_t count;    /* in use */
    size_t capacity; /* allocated */
};

static int stack_grow(stack_t* s);

Header: typedef struct X x_t;, prototypes with one-line contracts, module prefix on every name. Source: the struct body, static helpers, the definitions. Client: holds an x_t* only; s->member is a compile error there.

Where every byte lives

InvariantMeaning
count <= capacityNever write items[count] without checking this first.
items is live, capacity intsThe only pointer to block B. Replaced only by a successful realloc.
items[0..count) are the valuesBottom at 0, top at count - 1. Slots at or past count are garbage.

Push: check, grow, write

static int stack_grow(stack_t* s) {
    size_t new_capacity = s->capacity * 2;
    int* bigger = realloc(s->items, new_capacity * sizeof *bigger);
    if (bigger == NULL) return 0;          /* old block still owned, untouched */
    s->items = bigger;                     /* old pointer is dead from here */
    s->capacity = new_capacity;
    return 1;
}

int stack_push(stack_t* s, int value) {
    if (s->count == s->capacity && !stack_grow(s)) return 0;   /* stack intact */
    s->items[s->count] = value;
    s->count++;
    return 1;
}
CapacityGrows at pushInts copied
2 → 43rd2
4 → 85th4
8 → 169th8

Doubling copies fewer than n ints over n pushes: constant amortised cost per push (Sedgewick & Wayne). Growing by one would copy about n²/2.

Pop and peek: status plus out-parameter

int stack_pop(stack_t* s, int* out) {
    if (s->count == 0) return 0;           /* *out untouched */
    s->count--;
    *out = s->items[s->count];
    return 1;
}
int stack_peek(const stack_t* s, int* out) {
    if (s->count == 0) return 0;
    *out = s->items[s->count - 1];
    return 1;
}
/* client */
int value;
while (stack_pop(s, &value)) printf(" %d", value);

No int is free to mean “empty”, so the status is the return and the value goes through the address. Pop lowers count; it neither clears the slot nor shrinks the block.

New and free: two blocks, inside out

stack_t* stack_new(void) {
    stack_t* s = malloc(sizeof *s);
    if (s == NULL) return NULL;
    s->items = malloc(INITIAL_CAPACITY
                      * sizeof *s->items);
    if (s->items == NULL) {
        free(s);            /* undo A */
        return NULL;
    }
    s->count = 0;
    s->capacity = INITIAL_CAPACITY;
    return s;
}
void stack_free(stack_t* s) {
    if (s == NULL) return;
    free(s->items);         /* B, reached through A */
    free(s);                /* A */
}

Allocate outer then inner; free inner then outer. If the inner allocation fails, undo the outer before returning NULL.

Reports and symptoms

SymptomLikely mistake
gcc: invalid use of incomplete typedef ‘stack_t’A client touched a member. Use the module's functions; only stack.c sees the struct body.
gcc: invalid application of ‘sizeof’ to incomplete typeA client tried sizeof(stack_t) or a stack_t local. Only a stack_t* is allowed there.
heap-buffer-overflow, WRITE, 0 bytes after N-byte region, in stack_pushWrote items[count] before growing. Check, grow, then write.
heap-use-after-free, READ of size 8, in stack_free (gcc also warns -Wuse-after-free)Freed the struct before the items block. Free inside out.
