Binary Search Tree

Opaque bst_t, one recursive helper per operation, slot insert, post-order free, and the ownership contract of a borrowed pointer. Paired with Lesson 12.

Invariant. At every node, every key in the left subtree is smaller and every key in the right subtree is larger. No duplicates. Every operation relies on it or preserves it.

Interface

bst.h

typedef struct bst bst_t;                     /* opaque: struct bst lives only in bst.c */

bst_t*     bst_new(void);                     /* NULL on allocation failure */
void       bst_free(bst_t* t);                /* consumes ownership; NULL is a no-op */
int        bst_insert(bst_t* t, int key);     /* 1 inserted; 0 duplicate or alloc fail, tree unchanged */
int        bst_contains(const bst_t* t, int key);
const int* bst_min(const bst_t* t);           /* borrowed; NULL if empty; dies with bst_free */
int        bst_height(const bst_t* t);        /* -1 empty, 0 single node */
void       bst_print_inorder(const bst_t* t); /* " k1 k2 ... kn\n", ascending */
size_t     bst_count(const bst_t* t);

Private layout

struct node {
    int key;               /* 4 bytes */
    struct node* left;     /* +4 padding, 8 */
    struct node* right;    /* 8: node is 24 bytes */
};

struct bst {
    struct node* root;
    size_t count;
};

Ownership: the tree owns the root node; every node owns the two nodes its pointers address; NULL owns nothing. Seven nodes plus one struct bst means 8 allocations and 8 frees. make check reports 9 and 9: the ninth is printf's buffer.

The public function unpacks t->root (or &t->root) and calls the helper. The helper is static and takes struct node*, a type the header never names. The stack holds at most height + 1 frames at once. Sorted input gives height n - 1; with a 1 MB stack, 40,000 sorted inserts overflowed it.

The two shapes to remember

insert: write through the slot

static int insert_at(struct node** slot, int key) {
    if (*slot == NULL) {
        *slot = new_node(key);
        return *slot != NULL;
    }
    struct node* n = *slot;
    if (key < n->key) return insert_at(&n->left, key);
    if (key > n->key) return insert_at(&n->right, key);
    return 0;
}
/* wrapper: insert_at(&t->root, key), add result to t->count */

free: children before the node

static void free_nodes(struct node* n) {
    if (n == NULL) return;
    free_nodes(n->left);
    free_nodes(n->right);
    free(n);
}
/* wrapper: free_nodes(t->root); free(t); */

Height by hand: leaf = 1 + max(-1, -1) = 0; parent of two leaves = 1; root of the 7-key tree = 2.
