Hashmap

String keys, int values. Opaque hashmap_t, djb2 over the key, one chain per bucket, a map that owns a copy of every key, a load-factor rule that doubles the bucket array, and a resize that moves nodes without copying anything. Paired with Lesson 13.

Invariants. Every key is in exactly one node. That node is in the chain of bucket hash(key) % capacity. Every node owns its key copy and the node after it. count equals the number of nodes. Every function relies on these or restores them before returning.

Interface

hashmap.h

#pragma once
#include <stddef.h>

typedef struct hashmap hashmap_t;                 /* opaque: struct body lives in hashmap.c */

hashmap_t* hashmap_new(void);                     /* empty map, or NULL on failure */
void       hashmap_free(hashmap_t* m);            /* every key copy, every node, the array, then m; NULL ok */
int        hashmap_put(hashmap_t* m, const char* key, int value);  /* insert or overwrite; stores its OWN copy of key;
                                                                      1 ok, 0 alloc failed (no key added, no value changed) */
const int* hashmap_get(const hashmap_t* m, const char* key);       /* borrowed, or NULL; owned by the map, dies with
                                                                      hashmap_remove of that key and with hashmap_free */
int        hashmap_remove(hashmap_t* m, const char* key);          /* 1 removed (key copy and node freed), 0 absent */
size_t     hashmap_count(const hashmap_t* m);                      /* number of keys */
size_t     hashmap_capacity(const hashmap_t* m);                   /* number of buckets; doubles on resize */

From <string.h>: strcmp to compare keys, strdup to copy them (POSIX; declared under -std=gnu11). Nothing else.

Private layout

hashmap.c, top

#define INITIAL_CAPACITY 4

struct node {
    char* key;             /* 8: owned copy from strdup */
    int value;             /* 4, then 4 of padding */
    struct node* next;     /* 8: node is 24 bytes */
};

struct hashmap {
    struct node** buckets; /* capacity slots of 8 bytes */
    size_t capacity;
    size_t count;          /* struct is 24 bytes */
};

Four ownership levels: main owns the struct; the struct owns the array; each slot owns its chain; each node owns its key copy and the next node.

Allocation count for the lesson's test: 1 struct + 1 array of 4 + 6 nodes + 6 key copies + 1 array of 8 (the resize) = 15. make check reports 16 and 16: the sixteenth is printf's buffer.

Hash, then index

static unsigned long hash_djb2(const char* s) {
    unsigned long hash = 5381;
    for (; *s != '\0'; s++) {
        hash = hash * 33 + *s;    /* (hash << 5) + hash + c */
    }
    return hash;
}

static size_t index_of(const hashmap_t* m, const char* key) {
    return hash_djb2(key) % m->capacity;
}

unsigned long because pear alone reaches 6,385,579,149: unsigned wraparound is defined, signed overflow is not.

Load factor and the resize rule

BucketsThreshold (capacity × 3 / 4)Resize happens when
43the 4th key is added (count 4 > 3): double to 8

1612the 13th key is added: double to 32

Load factor = count / capacity = average chain length. Without resizing, the six keys in 4 buckets give 1.5 on average and a longest chain of 3 (mango → apple → fig). Sedgewick and Wayne: search and insert cost is “proportional to N/M”; their table doubles at an average of 10 and halves at 2. Weiss's C table takes a prime size once and never resizes. Any fixed threshold gives amortised constant cost per put, as with lesson 9's doubling stack.

The two shapes to remember

grow: relink, copy nothing, free only the old array

static int hashmap_grow(hashmap_t* m) {
    size_t new_capacity = m->capacity * 2;
    struct node** bigger = calloc(new_capacity, sizeof *bigger);
    if (bigger == NULL) return 0;
    for (size_t i = 0; i < m->capacity; i++) {
        struct node* n = m->buckets[i];
        while (n != NULL) {
            struct node* next = n->next;      /* save first */
            size_t j = hash_djb2(n->key) % new_capacity;
            n->next = bigger[j];
            bigger[j] = n;
            n = next;
        }
    }
    free(m->buckets);
    m->buckets = bigger;
    m->capacity = new_capacity;
    return 1;
}
/* called at the end of put: if (count > capacity * 3 / 4) */

remove: lesson 10's slot walk from the bucket

int hashmap_remove(hashmap_t* m, const char* key) {
    struct node** link = &m->buckets[index_of(m, key)];
    while (*link != NULL && strcmp((*link)->key, key) != 0) {
        link = &(*link)->next;
    }
    if (*link == NULL) return 0;
    struct node* gone = *link;
    *link = gone->next;
    free(gone->key);          /* key before node */
    free(gone);
    m->count--;
    return 1;
}

Put: hash, find_in the chain; found means overwrite and return 1; else malloc node, strdup key, push at the chain head, count++, then the grow check. Free: for each bucket, saved-next walk freeing key then node; then the array; then the struct.

A set is this structure with the value member deleted: set_add returns whether the key was new, set_contains returns 1 or 0, and no borrowed pointer exists.
