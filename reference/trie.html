Trie

Opaque trie_t, one heap node per letter of every path, 26 child slots per node indexed by c - 'a', insert through the slot, one finder for two questions, post-order free with a loop. Paired with Lesson 15 (optional; the required sequence ended with lesson 14).

Invariant. Slot i of a node leads to the node for letter 'a' + i, or holds NULL. A word is a path from the root, and is_end on the last node says the path is a whole word. count equals the number of nodes with is_end set. Every node is one calloc, so a fresh node has 26 NULL slots and is_end 0.

Interface

trie.h

#pragma once
#include <stddef.h>

typedef struct trie trie_t;                            /* opaque: struct body lives in trie.c */

trie_t* trie_new(void);                                /* empty trie (a root node), or NULL on failure */
void    trie_free(trie_t* t);                          /* frees every node, children before parent, then t; NULL is fine */
int     trie_insert(trie_t* t, const char* word);      /* 1 inserted, 0 already present, -1 bad char or alloc fail
                                                          (on -1: no word counted; a partial path may remain, owned) */
int     trie_contains(const trie_t* t, const char* word);      /* 1 if word was inserted as a whole word */
int     trie_starts_with(const trie_t* t, const char* prefix); /* 1 if the path for prefix exists; "" is the root, so 1 */
size_t  trie_count(const trie_t* t);                   /* number of whole words */
size_t  trie_node_size(void);                          /* sizeof(struct node), for the test program: 216 */

Every answer is an int or a size_t. No pointer into a node crosses the header, so no caller can hold a node after trie_free. No <string.h> function is needed: every walk reads one char at a time and stops at '\0'.

Private layout

trie.c, top

#define ALPHABET 26

struct node {
    struct node* child[ALPHABET]; /* 26 x 8 = 208 */
    int is_end;                   /* +4, +4 padding */
};                                /* 216 bytes */

struct trie {
    struct node* root;            /* always live */
    size_t count;
};                                /* 16 bytes */

after "app", then "apple"

0x6000 "apple"  is_end 1, all slots NULL

Slot i of the node at N lives at N + 8i. Six nodes, 156 slots, five in use.

Ownership: the trie owns the root; every node owns the nodes its 26 slots address; NULL owns nothing. The six test words (apple app apply banana band bandana) make 16 letter nodes plus the root: 17 nodes and one trie struct, 18 allocations and 18 frees. make check reports 19 and 19: the nineteenth is printf's buffer.

A char is a small integer, so the subtraction is plain arithmetic. Check the range first, in one static int slot_index(char c) that returns the slot or -1; both the insert walk and the finder call it.

The three shapes

insert: address of the slot, write through it

struct node* cur = t->root;
for (const char* p = word; *p != '\0'; p++) {
    int i = slot_index(*p);
    if (i < 0) return -1;
    struct node** slot = &cur->child[i];
    if (*slot == NULL) {
        *slot = new_node();        /* calloc */
        if (*slot == NULL) return -1;
    }
    cur = *slot;
}
if (cur->is_end) return 0;
cur->is_end = 1;
t->count++;
return 1;

find: one walk, two questions

static const struct node*
find_node(const struct node* root, const char* s) {
    const struct node* cur = root;
    for (const char* p = s; *p != '\0' && cur != NULL; p++) {
        int i = slot_index(*p);
        if (i < 0) return NULL;
        cur = cur->child[i];
    }
    return cur;   /* node at the end of s, or NULL */
}
/* contains:    n != NULL && n->is_end */
/* starts_with: n != NULL             */

free: all 26 slots, then the node

static void free_nodes(struct node* n) {
    if (n == NULL) return;
    for (int i = 0; i < ALPHABET; i++)
        free_nodes(n->child[i]);
    free(n);
}
/* wrapper: free_nodes(t->root); free(t); */

Lookups by hand on the diagram: "ap" reaches 0x3000, is_end 0, so contains 0 and starts_with 1. "cat" meets NULL at root->child[2]: both 0. "" reaches the root: starts_with 1 for every trie. Recursion depth of free_nodes is the longest word plus one: bandana gives eight frames. Each node makes 26 calls; 17 nodes make 442, and 425 of them meet NULL.

Cost

OperationCostWhy
insert, contains, starts_withlength of the stringOne slot per letter, no comparison against other words. algs4's 256-way TrieST states it: “time proportional to the length of the key (in the worst case)”.
free26 calls per nodeEvery slot is visited, used or not. Depth is the longest word plus one frame.
space216 bytes per node, shared prefixes share nodesSix words, 30 letters: 17 nodes, 3,672 bytes, 16 of 442 slots in use. That is the trade a trie makes.
