Sort and Search

Swap through pointers, insertion sort, half-open binary search, and the size_t rules that keep them inside the block. Paired with Lesson 5.

Swap

void swap_ints(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
swap_ints(&x[j], &x[j - 1]);   /* pass addresses, not values */

A parameter is a copy. To change the caller's variable, receive its address and write through it.

Insertion sort

Invariant: before handling index i, a[0..i) is sorted. Each pass walks a[i] left until its left neighbour is no larger.

void insertion_sort(int* a, size_t n) {
    for (size_t i = 1; i < n; i++) {
        for (size_t j = i; j > 0 && a[j] < a[j - 1]; j--) {
            swap_ints(&a[j], &a[j - 1]);
        }
    }
}

Good for small or nearly sorted arrays. Swaps equal the number of inversions, so a nearly sorted input is nearly free.

Binary search, half-open

Precondition: the array is sorted ascending. Invariant: every remaining candidate is in [lo, hi).

const int* search_sorted(const int* a, size_t n, int target) {
    size_t lo = 0;
    size_t hi = n;                      /* exclusive */
    while (lo < hi) {
        size_t mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return &a[mid];
        if (a[mid] < target) lo = mid + 1;
        else                 hi = mid;
    }
    return NULL;
}

Test by checking the postcondition

int is_sorted(const int* a, size_t n) {
    for (size_t i = 1; i < n; i++) {
        if (a[i] < a[i - 1]) return 0;
    }
    return 1;
}
printf("sorted: %s\n", is_sorted(a, n) ? "yes" : "no");
