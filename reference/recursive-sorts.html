Recursive Sorts

Merge sort with one owned scratch block, in-place quicksort, and the frame and size_t rules that keep the recursion finite. Paired with Lesson 8.

Interface

sort.h

void swap_ints(int* a, int* b);              /* lesson 5 */
int  is_sorted(const int* a, size_t n);      /* lesson 5 */
void merge_sort(int* a, size_t n);           /* one heap scratch block, freed inside */
void quick_sort(int* a, size_t n);           /* in place */

The recursive workers take (a, lo, hi) and are static in sort.c. A client sees (a, n) only.

Where every byte lives

stack (one frame per call)                        heap
main               a ──────────────────────────▶  [ n ints ]   owner: main
merge_sort         a, n, scratch ──────────────▶  [ n ints ]   owner: merge_sort
merge_sort_range   a, lo=0, hi=8, scratch         (borrows both)
merge_sort_range   a, lo=0, hi=4, scratch         (borrows both)
merge_sort_range   a, lo=0, hi=2, scratch         (borrows both)
merge_sort_range   a, lo=0, hi=1, scratch         base case: returns
Arguments are copies. lo and hi are private to each frame; every copy of a is the same address, so every frame writes into the same block. The frame that called malloc is the one that calls free.

Merge sort

Invariant after merge_sort_range(a, lo, hi, scratch): a[lo..hi) is sorted. The merge copies into scratch[lo..hi), then back into a[lo..hi). Ties take the left run (stable).

static void merge(int* a, size_t lo, size_t mid, size_t hi, int* scratch) {
    size_t i = lo, j = mid, k = lo;
    while (i < mid && j < hi) {
        if (a[j] < a[i]) scratch[k++] = a[j++];
        else             scratch[k++] = a[i++];
    }
    while (i < mid) scratch[k++] = a[i++];
    while (j < hi)  scratch[k++] = a[j++];
    for (k = lo; k < hi; k++) a[k] = scratch[k];   /* exactly [lo, hi) */
}

static void merge_sort_range(int* a, size_t lo, size_t hi, int* scratch) {
    if (hi - lo < 2) return;                       /* count, not endpoints */
    size_t mid = lo + (hi - lo) / 2;
    merge_sort_range(a, lo, mid, scratch);
    merge_sort_range(a, mid, hi, scratch);
    merge(a, lo, mid, hi, scratch);
}

void merge_sort(int* a, size_t n) {
    if (n < 2) return;
    int* scratch = malloc(n * sizeof *scratch);    /* once */
    if (scratch == NULL) return;                   /* a unchanged */
    merge_sort_range(a, 0, n, scratch);
    free(scratch);                                 /* once, by the owner */
}

Quicksort

Postcondition of partition: returns p with a[lo..p) <= a[p] <= a[p+1..hi). a[p] never moves again. Scans stop on equal keys.

static size_t partition(int* a, size_t lo, size_t hi) {  /* hi - lo >= 1 */
    int pivot = a[lo];
    size_t i = lo + 1;                       /* stops on >= pivot */
    size_t j = hi - 1;                       /* stops on <= pivot */
    for (;;) {
        while (i < hi && a[i] < pivot) i++;
        while (a[j] > pivot) j--;            /* a[lo] == pivot stops it at lo */
        if (i >= j) break;
        swap_ints(&a[i], &a[j]);
        i++; j--;
    }
    swap_ints(&a[lo], &a[j]);
    return j;
}

static void quick_sort_range(int* a, size_t lo, size_t hi) {
    if (hi - lo < 2) return;
    size_t p = partition(a, lo, hi);
    quick_sort_range(a, lo, p);              /* p itself is excluded */
    quick_sort_range(a, p + 1, hi);
}

void quick_sort(int* a, size_t n) { quick_sort_range(a, 0, n); }
