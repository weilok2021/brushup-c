Graph (adjacency lists)

Opaque graph_t: an array of list heads, two 16-byte nodes per undirected edge, front insertion, breadth-first search on lesson 11's queue, recursive depth-first search, and connected components. Paired with Lesson 14.

The rule. Mark a vertex when it is found: when BFS enqueues it, when a recursive helper enters it. Never when it is visited. A mark means “already in the queue or out of it”. Break the rule and a vertex is queued twice (BFS) or a cycle recurses forever (DFS).

Interface

graph.h

typedef struct graph graph_t;                      /* opaque: struct graph lives only in graph.c */

graph_t* graph_new(size_t vertex_count);           /* vertices 0 .. n-1, no edges; NULL on failure */
void     graph_free(graph_t* g);                   /* every edge node, the array, then g; NULL ok */
int      graph_add_edge(graph_t* g, int u, int v); /* v joins u's list AND u joins v's; 1 ok, 0 bad vertex or alloc fail, unchanged */
size_t   graph_vertex_count(const graph_t* g);
size_t   graph_degree(const graph_t* g, int v);    /* length of v's list */
void     graph_print(const graph_t* g);            /* "v:" then " nbr" each, one line per vertex */
size_t   graph_bfs(const graph_t* g, int start, int* order);      /* order[] holds n ints; returns visited count */
size_t   graph_dfs(const graph_t* g, int start, int* order);      /* same contract, recursive */
size_t   graph_components(const graph_t* g, int* component);      /* component[v] = id 0..; returns id count */

graph.c includes queue.h; main.c never sees a queue. Vertex ids are int because the queue carries int.

Private layout

graph.c, top

struct edge {
    int to;                /* 4 bytes + 4 padding */
    struct edge* next;     /* 8: node is 16 bytes */
};

struct graph {
    size_t n;
    struct edge** adj;     /* adj[u]: head of u's list */
};                         /* 16 bytes */

newest neighbour first: reverse insertion order

Ownership: main owns the struct through g; the struct owns the array (calloc, so every head starts NULL); each slot adj[u] owns u's nodes. Six edges are twelve nodes; with the struct and the array, 14 blocks. The lesson's test program totals 32 allocations and 32 frees: 14 graph blocks, 3 marked arrays, 2 queue structs, 10 queue nodes, 2 arrays in main, 1 printf buffer.

Add an edge: two nodes, four pointer writes

struct edge* uv = malloc(sizeof *uv);      /* allocate both first, so a failed second */
struct edge* vu = malloc(sizeof *vu);      /* malloc leaves the graph unchanged      */
if (uv == NULL || vu == NULL) { free(uv); free(vu); return 0; }
uv->to = v;  uv->next = g->adj[u];  g->adj[u] = uv;    /* front insert on slot adj[u] */
vu->to = u;  vu->next = g->adj[v];  g->adj[v] = vu;    /* front insert on slot adj[v] */

BFS core

marked[start] = 1;
queue_enqueue(q, start);
while (queue_dequeue(q, &v)) {
    order[count++] = v;
    for (e = g->adj[v]; e; e = e->next)
        if (!marked[e->to]) {
            marked[e->to] = 1;   /* here */
            queue_enqueue(q, e->to);
        }
}
queue_free(q); free(marked);

DFS helper

static void dfs_visit(const graph_t* g, int v,
        int* marked, int* order, size_t* count) {
    marked[v] = 1;               /* first */
    order[(*count)++] = v;
    for (e = g->adj[v]; e; e = e->next)
        if (!marked[e->to])
            dfs_visit(g, e->to, marked, order, count);
}
/* components: fill -1; for each v == -1:
   label_visit(g, v, component, id++) */
