Structs and Pointers

Declaring a struct, dot versus arrow, what happens to an array at a function call, what sizeof measures, and the pointer-walk idiom. Lookup only, nothing here is to be memorised. Paired with Lesson 2.

Declaring and using a struct

in the header, next to the prototypes

struct rect {          /* type name: "struct rect" */
    int x, y;          /* members */
    int w, h;
};

later, when a type must hide its members (lesson 9)

typedef struct stack stack;   /* header: name only  */
struct stack { ... };         /* .c file: members   */

values

struct rect a = {1, 2, 3, 4};      /* positional     */
struct rect b = {.w = 3, .h = 4};  /* designated, C99;
                                      rest are zero   */
struct rect c = a;                 /* copies all four */
a.x = 7;                           /* c.x is still 1  */
struct rect grid[3];               /* grid[1].w       */
if (a == b) ...                    /* not allowed:
                                      compare members */

Source: Beej ch. 8, §8.1 declaring, §8.2 initialisers, §8.5 copying, §8.6 comparing.

Reaching a member

WriteMeaning
s.wMember w of the struct s.
p->wMember w of the struct p points at. Identical to (*p).w. cppreference
&sThe address of s: a struct rect *.
*pThe whole struct p points at. struct rect copy = *p; copies it.
&rs[i]  =  rs + iThe address of element i. Two spellings, one pointer.
&s.xThe address of one member: an int *, not a struct rect *.
Dot on a struct, arrow on a pointer to one. Both mistakes are compile errors; see the table at the end.

Passing and returning

PrototypeEffect
void f(struct rect r)By value. f works on a copy; its changes stay inside f.
int f(const struct rect *r)Read-only through r. Caller passes &s, rs + i or &rs[i].
void f(struct rect *r)f may write through r; the caller sees the changes.
const struct rect *find(const struct rect *rs, size_t n)Returns an address inside the caller's array. Valid until that array is freed. Never free the result.
struct rect rect_make(int x, int y)Returning by value is fine for small structs.

When to pass a pointer, per Beej §8.3: the function must change the caller's struct, or the struct is large enough that copying it costs more than copying a pointer. In this course, also: every ADT from lesson 9 on lives on the heap and is only reached through a pointer.

An array at a function call

An array expression, except as the operand of sizeof or &, “undergoes an implicit conversion to the pointer to its first element” (cppreference). Consequences:

FactSo
Inside the function the parameter is a pointer.Pass the length separately, as size_t n. Beej §6.6.2
void f(struct rect rs[]) means void f(struct rect *rs).The brackets are decoration. Write the pointer form so nobody is fooled.
sizeof rs / sizeof rs[0] on a parameter is 8 ÷ 16 = 0.The element-count trick works only in the scope that declared the array. Beej §6.2

What sizeof measures

Measured on WSL Ubuntu, gcc 13, 64-bit, with struct rect corners[4]; and struct rect *p = corners;.

ExpressionBytesWhy
sizeof(struct rect)16Four ints. Parentheses are required around a type name.
sizeof corners64The whole local array, 4 × 16.
sizeof p8A pointer, whatever it points at. Same for any function parameter.
sizeof *p16What it points at. No parentheses needed around an expression.
sizeof corners / sizeof corners[0]4Element count, in the declaring scope only.
sizeof(struct rect) after adding char tag;20Not 17: padding keeps every int aligned in an array of them. CS107 teaches the rule.
Size what you point at: malloc(n * sizeof *p). sizeof p is legal, silent under -Wall -Wextra, and wrong.

Result type is size_t; a struct's size includes “internal and trailing padding”. cppreference

Pointer arithmetic

WriteMeaning
p + iThe element i places after p. Counts elements, not bytes: the compiler multiplies by sizeof *p. Beej §11.1.1
p++Move p to the next element.
p[i]  =  *(p + i)Indexing is pointer arithmetic in different clothes. Beej §11.2
q - pThe number of elements from p to q. Counts elements, not bytes. The result has type ptrdiff_t; print it with %td. cppreference
p < qOrder of two pointers into the same array.
rs + nOne past the last element. May be formed and compared; must never be read or written. p - 1 from the first element is equally undefined.
void *No arithmetic and no dereference until cast. CS107's material; not used here.

Two ways to walk an array

by index

for (size_t i = 0; i < n; i++) {
    total += rect_area(&rs[i]);
}

by pointer (the shape every list and tree uses)

const struct rect *end = rs + n;
for (const struct rect *p = rs; p < end; p++) {
    total += rect_area(p);
}

Keep const on the walking pointer when the loop only reads; it is the same promise as const struct rect * in a prototype.
