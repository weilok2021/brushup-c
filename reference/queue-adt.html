Queue ADT

Linked queue with head and tail pointers, worst-case constant-time enqueue and dequeue, and the tail reset that keeps it from writing into freed memory. Paired with Lesson 11. Reused by lesson 14 for breadth-first search.

Interface

queue.h

#pragma once
#include <stddef.h>

typedef struct queue queue_t;               /* opaque: struct body lives in queue.c */

queue_t* queue_new(void);                   /* empty queue, or NULL on failure */
void     queue_free(queue_t* q);            /* frees every node, then q; NULL is fine */
int      queue_enqueue(queue_t* q, int v);  /* 1 ok, 0 if malloc failed; queue unchanged on 0 */
int      queue_dequeue(queue_t* q, int* out); /* 1 and *out set, or 0 if empty */
int      queue_peek(const queue_t* q, int* out); /* same as dequeue, node stays */
size_t   queue_count(const queue_t* q);
int      queue_is_empty(const queue_t* q);

Values leave through int* out plus a 1/0 return. No pointer into a node ever crosses the header, so no caller can hold a node after it is freed.

Private layout

queue.c

struct node {
    int value;            /* 4 bytes + 4 padding */
    struct node* next;    /* 8 bytes */
};                        /* 16 bytes per node */

struct queue {
    struct node* head;    /* oldest, NULL when empty */
    struct node* tail;    /* newest, NULL when empty */
    size_t count;
};                        /* 24 bytes */

After enqueue 10, 20, 30

stack        heap
q ---------> [head | tail | 3]
               |      |
               v      v
             [10|.]->[20|.]->[30|NULL]

main owns the queue struct through q. The queue struct owns every node. One queue_free releases all of it.

The two invariants

1. head == NULL exactly when tail == NULL. Both ends agree about emptiness.

2. tail->next == NULL whenever tail is set. The tail is the real last node.

True before and after every public call. Enqueue may test only tail and dequeue only head because of invariant 1. Check both whenever a function frees or links a node.

Enqueue and dequeue

int queue_enqueue(queue_t* q, int v) {
    struct node* n = malloc(sizeof *n);
    if (n == NULL) return 0;
    n->value = v;
    n->next = NULL;
    if (q->tail == NULL) q->head = n;
    else                 q->tail->next = n;
    q->tail = n;
    q->count++;
    return 1;
}
int queue_dequeue(queue_t* q, int* out) {
    if (q->head == NULL) return 0;
    struct node* old = q->head;
    *out = old->value;
    q->head = old->next;
    if (q->head == NULL) q->tail = NULL;
    free(old);
    q->count--;
    return 1;
}

Free walk (saved next)

struct node* cur = q->head;
while (cur != NULL) {
    struct node* next = cur->next;   /* read before free */
    free(cur);
    cur = next;
}
free(q);
