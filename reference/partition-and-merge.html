Partition and Merge

The two loops under the recursive sorts: Hoare's two-scan partition with its one guard and its equal-key stops, and the merge that takes the smaller head. Paired with Lesson 7.

Hoare's rules, in CS61B's words

Create L and G pointers at the left and right ends; L starts just right of the pivot. L is a friend to small items and hates large or equal items. G is a friend to large items and hates small or equal items. Walk them toward each other, stopping on a hated item. When both have stopped, swap and move both by one. When they cross, you are done walking: swap the pivot with G. In C, L is i and G is j. Click-through demos: lesson 7, or Josh Hug's original slides.

Partition: the promise

Precondition: hi - lo >= 1. Postcondition: returns p with a[lo..p) <= a[p] <= a[p+1..hi). The pivot a[p] is in its final sorted place. Neither side is sorted.

lo        lo+1 .. i-1        i .. j        j+1 .. hi-1
[ pivot ] [ known <= pivot ] [ unknown ] [ known >= pivot ]      invariant during the scans
size_t partition(int* a, size_t lo, size_t hi) {
    int pivot = a[lo];
    size_t i = lo + 1;                       /* stops on >= pivot */
    size_t j = hi - 1;                       /* stops on <= pivot */
    for (;;) {
        while (i < hi && a[i] < pivot) i++;  /* guard: pivot may be the largest */
        while (a[j] > pivot) j--;            /* no guard: a[lo] == pivot stops it */
        if (i >= j) break;                   /* crossed: unknown region empty */
        swap_ints(&a[i], &a[j]);
        i++; j--;
    }
    swap_ints(&a[lo], &a[j]);                /* pivot into its final slot */
    return j;
}

int is_partitioned(const int* a, size_t lo, size_t hi, size_t p) {
    for (size_t k = lo; k < p; k++)     if (a[k] > a[p]) return 0;
    for (size_t k = p + 1; k < hi; k++) if (a[k] < a[p]) return 0;
    return 1;
}

Merge: take the smaller head

The smallest item of both runs is at the front of one of them: compare the two fronts, copy the smaller into scratch, repeat until one run is empty, then copy the rest of the other (demo).

Precondition: a[lo..mid) and a[mid..hi) each sorted; scratch has room for index hi - 1. Invariant: scratch[lo..k) holds the k - lo smallest values of both runs, in order. Ties take the left run (stable).

void merge(int* a, size_t lo, size_t mid, size_t hi, int* scratch) {
    size_t i = lo, j = mid, k = lo;
    while (i < mid && j < hi) {
        if (a[j] < a[i]) scratch[k++] = a[j++];
        else             scratch[k++] = a[i++];   /* ties: left */
    }
    while (i < mid) scratch[k++] = a[i++];        /* one of these two */
    while (j < hi)  scratch[k++] = a[j++];        /* copies the leftover run */
    for (k = lo; k < hi; k++) a[k] = scratch[k];  /* copy back exactly [lo, hi) */
}

merge borrows scratch. The owner is whoever called malloc: main in lesson 7, the merge_sort wrapper in lesson 8.

Closed range: the lines that differ

Counts: half-open [0, 8) holds hi - lo = 8; closed [0, 7] holds high - low + 1 = 8. One convention per function, header included.
