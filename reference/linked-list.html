Singly Linked List

Opaque list_t, heap nodes owned by the list, and one node_t** slot walk for insert and remove with no head special case. Paired with Lesson 10.

Interface and private layout

list.h

typedef struct list list_t;

list_t* list_new(void);            /* NULL on failure */

list.c, private

typedef struct node node_t;

struct node {
    int     value;   /* 4 + 4 padding */
    node_t* next;    /* 8: a slot */
};                   /* 16 bytes */

struct list {
    node_t* head;    /* a slot */
    size_t  count;
};                   /* 16 bytes */

Where every byte lives

main's frame            heap
+---------+             +------------+      +-----------+      +-----------+
| l  o----+------------>| head  o----+----->| value  1  |   +->| value  3  |
+---------+             | count  2   |      | next   o--+---+  | next NULL |
                        +------------+      +-----------+      +-----------+
                          list_t              node_t             node_t

Ownership. main owns the list through the handle l. The list owns every node. No node pointer ever leaves list.c, so nothing outside can free one.

Invariants to keep on every path: count equals the number of nodes; the last node's next is NULL; each node is reachable from exactly one slot. Empty list: head == NULL, count == 0.

The slot walk

Every slot that holds a node_t* has an address of type node_t**. &l->head is the slot before the first node; &(*link)->next is the slot inside the node ahead. The same loop reaches the front, the middle and the end.

slot              address   holds
l->head           0x500     node 1        link starts here: &l->head
(node 1)->next    0x618     node 3        link = &(*link)->next
(node 3)->next    0x628     node 7
(node 7)->next    0x638     NULL          the walk stops here at the latest

insert in order

node_t** link = &l->head;
while (*link != NULL && (*link)->value < v)
    link = &(*link)->next;
node_t* n = node_new(v, *link);  /* next first */
if (n == NULL) return 0;
*link = n;                       /* slot second */
l->count++;
return 1;

remove by value

node_t** link = &l->head;
while (*link != NULL && (*link)->value != v)
    link = &(*link)->next;
if (*link == NULL) return 0;
node_t* gone = *link;
*link = gone->next;              /* skip over */
free(gone);
l->count--;
return 1;

&(*link)->next needs its parentheses: -> binds tighter than *. Push front is the insert with an empty walk: n = node_new(v, l->head); l->head = n;.

Reverse

iterative, three pointers, ship this

node_t* prev = NULL;
node_t* cur = l->head;
while (cur != NULL) {
    node_t* next = cur->next;  /* save */
    cur->next = prev;          /* flip */
    prev = cur;
    cur = next;
}
l->head = prev;

recursive, one frame per node

static node_t* reverse_rec(node_t* head) {
    if (head == NULL || head->next == NULL)
        return head;
    node_t* new_head = reverse_rec(head->next);
    head->next->next = head;   /* old second is the tail */
    head->next = NULL;
    return new_head;
}
/* l->head = reverse_rec(l->head); */
prev   cur   next    flip
NULL   1     3       1->next = NULL
1      3     7       3->next = 1
3      7     NULL    7->next = 3     head = 7    result: 7 3 1

Free and print

void list_free(list_t* l) {
    if (l == NULL) return;
    node_t* cur = l->head;
    while (cur != NULL) {
        node_t* next = cur->next;  /* before free */
        free(cur);
        cur = next;
    }
    free(l);
}
void list_print(const list_t* l) {
    const char* sep = "";
    for (const node_t* cur = l->head;
         cur != NULL; cur = cur->next) {
        printf("%s%d", sep, cur->value);
        sep = " ";
    }
    printf("\n");
}

Save the rest, then destroy. Any loop that changes or frees the thing it walks on reads next into a local first. Reverse and free both have this shape.
