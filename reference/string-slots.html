String Slots

C-string operations, arrays of owned strings, and what each level of char** reaches. Paired with Lesson 4.

OperationMeaning
strlen(p)Characters before '\0'; result is size_t.
strcmp(a, b) == 0Equal string contents.

Pointer equality (a == b) compares addresses. strcmp compares string contents, and zero means equal.

Literal, alias, and copy

CodeOwnership

Why pass char**?

receives a copy; caller's slot unchanged

void wrong(char* current) {
    current = strdup("new");
}

receives slot address; caller's slot changes

int replace(char** slot) {
    char* copy = strdup("new");
    if (copy == NULL) return 0;
    free(*slot);
    *slot = copy;
    return 1;
}

Use a pointer-to-pointer when a function must change a pointer variable owned by its caller. For an array element, pass &words[i].

Replace without losing the old value

char* copy = strdup(replacement);  /* allocate first */
if (copy == NULL) {
    return 0;                      /* old *slot survives */
}
free(*slot);                       /* then end old value */
*slot = copy;                      /* transfer new ownership */
return 1;
Allocate first, free second, assign third. Failure then leaves the caller's slot unchanged.

Build and destroy an array of owned strings

partial construction

char** words = calloc(n, sizeof *words);
if (words == NULL) return 1;

for (size_t i = 0; i < n; i++) {
    words[i] = strdup(source[i]);
    if (words[i] == NULL) {
        words_free(words, i);
        return 1;
    }
}

reverse-order cleanup by level

void words_free(char** words, size_t n) {
    for (size_t i = 0; i < n; i++) {
        free(words[i]);
    }
    free(words);
}

At failure index i, exactly i strings were successfully created. Free those inner blocks, then the outer array.

Useful parameter forms

DeclarationWhat the function can change through it
char** slotThe slot's char* and its characters.
char** words (read-only by contract)Anything; the function promises in its comment not to reassign slots. Stricter char* const* deferred to a later lesson.
const char* sNeither characters through s; s itself may move.

Do not force every possible const combination into one declaration. Use the minimum form that states the function's actual promise.
