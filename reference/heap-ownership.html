Heap Ownership

Where pointers and blocks live, what each allocator promises, the safe realloc pattern, and how to recognize lifetime failures. Paired with Lesson 3.

Pointer versus heap block

int* values = calloc(4, sizeof *values);

stack frame                          heap
+------------------+                +---------------+
| values: address -+--------------->| 0 | 0 | 0 | 0 |
+------------------+                +---------------+
ObjectLifetime
Local pointer valuesAutomatic: ends when its block or function returns.
Four-int heap blockManual: ends at free or successful realloc.
Losing or changing the pointer does not free its heap block. Freeing the block does not erase pointers that contain its old address.

The allocation API

CallInitial contentsFailure
malloc(n * sizeof *p)Uninitialised. Write before reading.Returns NULL.
calloc(n, sizeof *p)All bytes zero.Returns NULL.
realloc(p, n * sizeof *p)Preserves existing bytes that fit. Added bytes are uninitialised.Returns NULL; the old block remains allocated and unchanged.
free(p)Ends the block's lifetime.free(NULL) safely does nothing.

Use positive, nonzero sizes in this course. The special rules for zero-size allocation are implementation-sensitive and unnecessary here.

Safe realloc

wrong: owner can be overwritten by null

values = realloc(values,
                 new_n * sizeof *values);
if (values == NULL) {
    /* old block leaked */
}

right: keep owner until success

int* grown = realloc(values,
                     new_n * sizeof *values);
if (grown == NULL) {
    free(values);
    return 1;
}
values = grown;
ResultOwnership
Success: non-NULLThe returned pointer owns the resized block. Do not use the input pointer or its aliases again.
Failure: NULLThe original pointer still owns the unchanged original block.
realloc may move the block. Use only its returned pointer after success.

Ownership words

TermRule
OwnerThe one pointer or code path responsible for eventually freeing the block.
BorrowerMay access the live block within its contract. Does not free it or retain it beyond the promised lifetime.
Ownership transferResponsibility for the eventual free moves to another pointer or caller.
Dangling pointerA stale pointer to a block whose lifetime ended through free or successful realloc. Do not dereference, compare, or free it.

State transitions

allocation succeeds       realloc succeeds           free
no block ------------> live owned block ---------> resized block ----> dead
                            |                              |
                            +-- realloc fails ------------+
                                old block remains live

Every successful allocation starts one ownership obligation. A successful realloc continues that obligation with its returned pointer. One free completes it.

Function contracts

ShapeTypical contract
int* make(size_t n)Returns ownership of a new block, or NULL.
int* resize(int* p, size_t n)On success returns the owner and invalidates use of the input pointer; on failure returns NULL and caller retains ownership of p.
int sum(const int* p, size_t n)Borrows for the call. Reads but neither changes nor frees the block.
void destroy(int* p)Consumes ownership and frees the block. The caller must not use aliases afterward.

const controls writes through a pointer. It does not express ownership or extend lifetime. Comments must state those parts of the contract.

Checklist for every heap block

[ ] Size from the pointee: n * sizeof *p
[ ] Check allocation result before dereference
[ ] Name one owner
[ ] Initialise before read
[ ] Keep the old owner until realloc succeeds
[ ] Use only realloc's result after success
[ ] Free once on every exit path
[ ] Do not use aliases after free or realloc
